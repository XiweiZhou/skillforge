# Technical Appendix: Email Scenario Walkthrough (Artifacts + Repro)

This appendix shows a concrete end-to-end walkthrough using the repository’s stored artifacts under `data/learning/`.

It covers:

- what error evidence was recorded
- what rule was learned
- what before/after metric was measured
- how to reproduce the run deterministically

---

## 1) The stored artifacts (what to open)

All of these files are generated by running the demo/scenario:

- `data/learning/errors.jsonl` — raw error records (JSON Lines)
- `data/learning/rules.json` — learned rules (condition → action)
- `data/learning/scenario_email_results.json` — baseline vs learning evaluation results
- `data/learning/demo_results.json` — top-level demo aggregation

---

## 2) Evidence: an error record captured during training

Open `data/learning/errors.jsonl`.

You’ll see records like:

```json
{"task": "Draft a follow-up email for the 10 AM call", "error_type": "TimezoneError", ...}
```

Key point: the record contains a context snapshot and can be replayed/analyzed later.

---

## 3) The learned guardrail: Condition → Action rule

Open `data/learning/rules.json`.

For the run currently checked into the repo, two prevention rules were generated (timezone + spam triggers). One example is the timezone rule:

- Conditions:
  - `task.description matches "\\d{1,2}\\s*(am|pm|AM|PM)"`
  - `context.has_timezone equals false`
- Actions:
  - `add_field context.timezone = "UTC"`
  - `flag timezone_added`

This is “white-box learning”: the improvement is an explicit artifact you can inspect.

## 4) The real before/after metric (ablation test)

Open `data/learning/scenario_email_results.json` and look at:

- `baseline.success_rate`
- `with_learning.success_rate`
- `improvement`

For the stored run in this repo (seed `20260208`):

- Baseline success rate: **0.66**
- With learning success rate: **0.96**
- Absolute improvement: **+0.30** (i.e., **+30 percentage points**)

Additional concrete signals:

- `with_learning.rules_applied_total = 28`
- `with_learning.errors_prevented = 28`
- `TimezoneError` count dropped from **8** (baseline) to **0** (with learning)
- `SpamTriggerError` count dropped from **6** (baseline) to **0** (with learning)

## 5) How to reproduce (deterministic)

The demo and scenario use randomness to sample tasks and inject errors. For stable blog-worthy numbers, use a fixed seed.

### Run the full demo

```bash
python3 demo.py --quiet --seed 20260208
```

### Or run only the scenario

```bash
python3 scenarios/scenario_email.py
```

Notes:

- The demo clears `data/learning/` before running.
- Results will be written back to `data/learning/`.

## 6) Quick sanity-check script (optional)

If you want a one-liner to print the before/after summary:

```bash
python3 - << 'PY'
import json
from pathlib import Path
p = Path('data/learning/scenario_email_results.json')
r = json.loads(p.read_text())
base = r['baseline']['success_rate']
learn = r['with_learning']['success_rate']
imp = r['improvement']
print(f"baseline={base:.0%} learned={learn:.0%} improvement={imp*100:+.1f} pp")
print('baseline errors:', r['baseline']['errors_by_type'])
print('learned errors:', r['with_learning']['errors_by_type'])
print('rules_applied_total:', r['with_learning']['rules_applied_total'])
PY
```

## 7) Mapping artifacts back to code
